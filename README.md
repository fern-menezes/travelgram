#  📸 Travelgram - Perfil de Viagens
O Travelgram é um projeto de perfil de uma rede social focada em fotos de viagem. O objetivo deste projeto é levar o layout a outro nível, transformando-o em uma página responsiva para diferentes dispositivos. Este projeto faz parte da formação Full-Stack, como parte dos conteúdos de especialização.

## 🚀 Tecnologias Utilizadas  
- 🌐 **HTML5**: Estruturação semântica do conteúdo.  
- 🎨 **CSS3**: Estilização e layout.  
- 🖥️ Design Responsivo: Adaptação da interface para diferentes tamanhos de tela.

  
## 🌟 Funcionalidades  
- **Layout Responsivo**: A página se ajusta automaticamente a dispositivos móveis, tablets e desktops.  
- **Interface Intuitiva**: Design pensado para destacar imagens e momentos de viagem.
- **Galeria de Fotos**: Estrutura ideal para apresentar imagens de diferentes tamanhos de forma elegante. 

## 🧠 Desafio Principal
O foco principal deste projeto foi implementar responsividade, garantindo que o site funcione perfeitamente em diversos tamanhos de tela. utilização do flex wrap para se ajustar a vários tipos de telas.
